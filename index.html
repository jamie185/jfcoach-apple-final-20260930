What changed

Every client screen in JF Coach was rebuilt to Apple's own rulebook for iPhone apps, in the real app rather than a mock-up. It now uses the iPhone's own text sizes, lists that look like Settings, glass buttons in the top bar, iPhone menus and sheets, one bright button per screen and bigger taps. It also follows the phone's Dark Mode and text size, which the current app doesn't. Your JF colours, the sky wash, the faded chapter pictures, the JFI orb, the mood faces, the tab bar and the + all stay. Nothing about what the app does has changed: same screens, same buttons, same saving.

Checked against Apple's documentation

Apple publishes a design guide for iPhone apps, the Human Interface Guidelines. We saved the whole guide and turned it into a 71-question review list. Each answer below links to the Apple page it comes from.

The design was independently reviewed by Codex gpt-6.1-sol, which checked the code and, separately, every screen, and by Claude, which swept every screen and sheet in light, dark and larger text. Every must-fix they found is fixed; the answers below are graded against the finished build.

Where we differ from Apple, on purpose

These are your standing rules. Each one is a deliberate choice, not a miss.

  1. One small round X at the top rightApple's sheets put Cancel on the left and Done on the right. Every JF Coach sheet instead has one small round X at the top right, so closing always works the same way. Apple does use the X symbol for Close, so it still feels at home. Apple: Sheets
  2. The round + in the tab barApple says tab bar buttons should only switch screens, never do something, and a + usually means "add". The round + stays at the bottom right and opens the JFI pop-up, as you decided. Apple: Tab bars
  3. JF's own iconsApple prefers its SF Symbols icons, but they are licensed for Apple devices only and JF Coach also ships on Android. JF's own icons are used everywhere, which Apple allows as long as they are consistent. Apple: SF Symbols
  4. A skip on the permission screensApple wants the screen before a permission request to have one button that leads to the iPhone's own prompt. JF Coach keeps "Skip for now" on the notification screen and "Not now" on the Health step, so no one is forced into a permission. Apple: Privacy
  5. No Delete Account buttonApple asks apps that create accounts to let people delete them inside the app, and App Review can ask about it. You've decided not to add it for now, so it's noted here. Apple: Managing accounts

Android

Android gets the same design. It's one app on both stores, so nothing had to be built twice.

The only visible difference is the font: iPhones show Apple's SF Pro, Android phones show Google's Roboto. No Apple fonts or Apple icons are shipped in the app, so Android is fully allowed. Dark Mode and Larger Text follow the Android phone's settings the same way.
